# Checkin Khách Dự — HNKH

Phần mềm checkin khách dự Hội nghị khách hàng, chạy trên trình duyệt (máy tính, điện thoại, iPad).

- Mở: https://dinhlbv2026-coder.github.io/checkin-hnkh/
- Nhiều máy cùng checkin: vào **Cài đặt → Đồng bộ nhiều máy (GitHub)**, nhập mã truy cập, cùng một **Mã sự kiện** và tên lễ tân.
- Dữ liệu đồng bộ nằm trong thư mục `data/<mã sự kiện>/`, mỗi máy một file.
